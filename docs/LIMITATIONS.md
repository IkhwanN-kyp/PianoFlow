# Batasan yang masih berlaku

- **Pengujian fisik belum dilakukan.** Tidak ada MatePad TGR-W09, P-145, kabel OTG, atau keyboard lampu fisik yang terhubung. Kompilasi dan emulator tidak menjamin layanan Android MIDI, descriptor USB, izin, audio routing atau latensi pada firmware HarmonyOS pengguna. Ini APK Android, bukan HarmonyOS NEXT/HAP.
- **Transkripsi perkiraan.** Basic Pitch mendeteksi pitch/onset/durasi polifonik, tetapi implementasi decoder streaming Android lebih sederhana daripada pipeline Python lengkap. Tidak ada stem separation, fingering, beat/tempo estimation atau hand inference dari audio. Audio campuran dapat menghasilkan harmonik palsu dan event yang perlu diperbaiki. Fallback DSP hanya monofonik.
- **Notasi pembelajaran.** Render tempo/meter/grand staff/highlight berfungsi, tetapi ejaan enharmonik memakai sharp sederhana, durasi visual dikuantisasi 1/16, empty-measure rests sederhana, dan beaming/ties lintas birama belum lengkap. Jangan menganggap PDF sebagai partitur siap terbit. MusicXML hanya score-partwise tak terkompresi; repeat/ornament/tie semantics kompleks tidak diekspansi.
- **MIDI.** SMF 0/1 PPQN dan SMPTE didukung; format 2 ditolak. Kanal drum 10 dikecualikan dari latihan piano, dan keyboard latihan A0–C8. Raw USB fallback MIDI 1 memakai virtual cable 0; UMP/MIDI 2 dan protokol lampu vendor tidak didukung. Setelah hot-unplug, pilih perangkat lagi. Rekaman mikrofon tidak tersedia.
- **Audio.** FluidSynth memakai SF2 nyata, tetapi kualitas tetap bergantung bank dan speaker. Bank impor yang tidak lengkap tidak menjamin 128 preset. Sustain/velocity playback dan input ada; kualitas teknik pedal dan dinamika tidak dinilai sebagai skor. Audio MIDI hardware belum diuji fisik. Permintaan low latency API tidak sama dengan latensi terukur.
- **Pagar sumber daya.** MIDI 64 MiB/500.000 event, MusicXML 16 MiB, SF2 1 GiB, model resmi sekitar 200 KiB, ekspor PDF maksimum 300 halaman, hasil transkripsi 250.000 not. Tidak ada batas komersial jumlah/durasi lagu, namun memori/disk perangkat tetap terbatas. Decode audio memakai disk streaming dan dapat dibatalkan.
- **Updater.** Memerlukan internet dan GitHub public API; rate limit, jaringan, installer OEM dan kebijakan unknown-source dapat memengaruhi proses. Tidak memasang diam-diam. Kanal Stable dapat kosong sampai ada rilis stabil. Fork dengan kunci lain ditolak. Uninstall atau clear data tetap menghapus data; update normal tidak melakukannya.
- **UI.** Dioptimalkan landscape tablet. Pembaca layar per tuts belum diimplementasikan. UI inti dua bahasa; diagnostik OS/library bisa berbahasa Inggris. Ketahanan sesi berjam-jam dan multitouch sepuluh jari pada tablet belum diuji.
